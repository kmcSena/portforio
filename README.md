# YASUMATSU SENA — Portfolio

安松星那の活動を紹介するReact製ポートフォリオサイトです。GitHub Actionsを利用してGitHub Pagesへ自動公開します。

## コンセプト

このポートフォリオのテーマは「異なる領域を行き来しながら、アイデアを形にする」です。私の制作は、グラフィックや服のように視覚と身体に関わるものだけでなく、イベントの企画やロボットの設計・制御まで広がっています。一見すると別々に見える活動を、完成品の種類ではなく、観察し、考え、試し、調整しながら形にする共通のプロセスとして伝えることを目指しました。閲覧者には、作品を順番に説明される受け身の体験ではなく、自分のペースで気になる領域を見つけ、詳細へ進める感覚を持ってもらいたいと考えています。そのため、トップページでは鮮やかな青を基調に、白い文字と青紫の抽象的なオブジェクトを強い視覚的な入口として配置しました。背景オブジェクトだけに水中のような揺らぎを与え、固定された白いロゴとの対比によって、発想が揺れ動きながらも自分の軸は変わらないという印象を表現しています。Worksは横スクロールで複数の活動を連続して眺められるようにし、写真を選ぶと詳細へ移動します。詳細ページでは左側に写真、右側に文章を置き、作品の見た目と考え方を同時に理解できる構成にしました。装飾を増やしすぎず、写真、文字、余白の差を大きくすることで、それぞれの作品が持つ個性を邪魔せず、ポートフォリオ全体として一貫した印象を作ることを狙っています。

## AI使用について

デザインのWeb実装、レスポンシブ調整、GitHub Pages向けの構成整理、GitHub Actions設定の補助に生成AIを使用しました。掲載内容と最終的なデザイン判断は制作者本人が確認・決定しています。
